# Skill: Amazon Working Backwards (Zolvency Edition)

## 🎯 Objetivo
Garantir que cada funcionalidade do Zolvency resolva um problema real e seja explicável de forma simples para o usuário final antes de ser codificada.

## 🛠️ O Processo (PR/FAQ)
Ao ativar esta skill, o Agente deve:

1. **Escrever o Press Release (Comunicado à Imprensa):**
   - Título: O que estamos lançando de forma impactante.
   - O Problema: Descrição vívida da dor do usuário.
   - A Solução: Como o Zolvency resolve isso de forma elegante.
   - Citação do Porta-voz: O valor estratégico do lançamento.
   - Citação do Usuário (Fictícia): Como a vida do usuário melhorou.

2. **Escrever o FAQ (Perguntas Frequentes):**
   - Perguntas do Cliente: "Quanto custa?", "É seguro?", "Como eu começo?".
   - Perguntas Técnicas/Stakeholders: "Como isso escala?", "Qual o impacto na rede Stellar?".

## 🚦 Critério de Sucesso
Se o Press Release não for empolgante ou o FAQ tiver respostas vagas, o PRD precisa ser revisado.
