# Skill: Jobs-to-be-Done (Zolvency Edition)

## 🎯 Objetivo
Entender o progresso que o usuário quer fazer, não apenas as features que ele quer usar.

## 📝 O Framework
Mapear cada feature para a estrutura:
**"Quando [situação], eu quero [ação], para que [resultado esperado]."**

## 🔍 Foco de Análise
- **Motivação Social:** "Como ter esse SBT me faz parecer para os outros protocolos?".
- **Motivação Funcional:** "Isso realmente me dá acesso a mais crédito?".
- **Motivação Emocional:** "Eu me sinto seguro usando minhas chaves aqui?".

## 🚦 Critério de Decisão
Features que não respondem a uma motivação clara de "progresso" devem ser simplificadas.
