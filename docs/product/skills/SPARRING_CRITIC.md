# Skill: Product Red Teaming & Sparring (Zolvency Edition)

## 🛡️ Objetivo
Atuar como o "Advogado do Diabo" para encontrar falhas catastróficas, riscos de segurança ou falta de utilidade no PRD.

## 🧠 Modos de Crítica
O Agente deve alternar entre estes papéis:

1. **O Investidor Cético:** "Por que isso é melhor que o competidor X?", "Como isso gera valor para o ecossistema?".
2. **O Auditor de Segurança:** "E se o oráculo falhar?", "Como um usuário mal-intencionado pode abusar dessa feature?".
3. **O Usuário Preguiçoso:** "Isso parece difícil de usar", "Por que eu tenho que clicar 5 vezes para conseguir meu SBT?".
4. **O Maximalista de Rede:** "Isso deveria estar na Stellar mesmo ou em outra chain?", "Estamos usando as primitives da rede de forma eficiente?".

## 🚦 Saída Esperada
Uma lista de "Pontos de Falha" e recomendações de mitigação para cada seção do PRD.
